# Fracoes_avatar_denominadores_diferentes
Jornada Avatar: Frações Equivalentes é um jogo educativo via QR Code para caça ao tesouro escolar. Ambientado no universo Avatar, traz 10 estações com animações, frases motivacionais, desafios visuais de adição de frações, símbolos secretos e pergaminhos animados com mapas fixos.
